# UI/UX Pro Max

## When to use this skill

- In every UI delivery.
- When performing design reviews.
- When optimizing interactions and layout.

## Workflow

- [ ] Check accessibility (contrast, touch targets).
- [ ] Verify responsiveness (375px to 1440px).
- [ ] Audit hover states and transitions.
- [ ] Ensure loading states for async operations.

## Instructions

### Design System (MANDATORY)
Use scripts for product/industry search and design system alignment.

### Checklist
- **Visual**: Use SVGs (Heroicons, Lucide), no emojis as icons. Hover states without layout shift.
- **Interactions**: `cursor-pointer` on clickable items, smooth transitions (150-300ms).
- **Accessibility**: Contrast 4.5:1, keyboard focus states, touch targets 44x44px.
- **Layout**: No horizontal scroll on mobile, content not hidden by fixed navbars.
