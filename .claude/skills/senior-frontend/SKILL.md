# Senior Frontend

## When to use this skill

- Building complex frontend features.
- Managing application state.
- Ensuring strict TypeScript usage and performance.

## Workflow

- [ ] Scrutinize component responsibility (Single Responsibility).
- [ ] Select appropriate state management (Local -> Context -> Zustand).
- [ ] Implement strict TypeScript types (no `any`).
- [ ] Verify accessibility and responsiveness.

## Instructions

- **Components**: Keep them small and focused.
- **State**: Prefer local state first. Use higher-level managers only when justified.
- **TypeScript**: Always use strict mode.
- **CSS**: Prefer Tailwind or CSS Modules.
