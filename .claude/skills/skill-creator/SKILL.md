# Skill Creator

## When to use this skill

- Creating a new specialized skill for the agent.
- Updating existing skills with new logic or scripts.
- Packaging and evaluating skill performance.

## Workflow

- [ ] Define the skill purpose and gerund name.
- [ ] Create the folder hierarchy (`SKILL.md`, `scripts/`).
- [ ] Implement the logic following the standard template.
- [ ] Validate and package the skill.

## Instructions

- **Hierarchy**: Always include `SKILL.md`. Others like `scripts/`, `resources/` are optional.
- **Templates**: Follow the YAML frontmatter and markdown structure exactly.
- **Conciseness**: Focus on unique logic, don't explain basics.
