# Senior Fullstack

## When to use this skill

- Integrating frontend components with backend APIs.
- Defining shared TypeScript types/interfaces.
- Implementing optimistic updates and shared error handling.

## Workflow

- [ ] Define shared API contracts between layers.
- [ ] Implement consistent error handling in front and back.
- [ ] Add loading and error states to all fetch operations.
- [ ] Implement optimistic updates for better UX.

## Instructions

- **Contracts**: Use shared types to ensure sync between layers.
- **UX**: Always provide feedback during async operations.
- **Scaffolding**: Use scripts to initiate full-stack project structures.
