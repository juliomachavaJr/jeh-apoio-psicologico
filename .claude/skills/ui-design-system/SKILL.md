# UI Design System

## When to use this skill

- Initializing a new project.
- Defining or updating core visual tokens (colors, font sizes, spacing).
- Building reusable component libraries.

## Workflow

- [ ] Initialize CSS variables in `:root`.
- [ ] Define spacing and typography scales.
- [ ] Implement light/dark themes.
- [ ] Create base atomic components.

## Instructions

- **CSS Tokens**: Define variables for colors, typography, spacing, radius, and shadows.
- **Consistency**: Use a fixed spacing scale and z-index scale.
- **Themes**: Use classes or `prefers-color-scheme` for theme switching.
- **Components**: Ensure isolation and reusability.
