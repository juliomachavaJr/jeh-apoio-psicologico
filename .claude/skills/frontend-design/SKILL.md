# Frontend Design

## When to use this skill

- Creating any new UI component or page.
- Modifying existing interfaces to improve aesthetics.
- When the user mentions "landing page", "dashboard", or "UI".

## Workflow

- [ ] Define the aesthetic direction (brutalist, minimalist, etc.).
- [ ] Select appropriate typography (display + body pairs).
- [ ] Define CSS color variables.
- [ ] Plan CSS animations/motion.
- [ ] Implement responsive layout.

## Instructions

### Design Guidelines

Before coding, define a clear and intentional aesthetic direction:
- **Tone**: Choose an extreme — brutalist, editorial, minimalist refined, etc.
- **Typography**: Use unique fonts from Google Fonts. NEVER use Inter, Roboto, or Arial.
- **Color**: CSS variables for consistency. Dominant colors with strong accents.
- **Motion**: CSS animations for page load (staggered reveals), hover states, scroll-triggered.
- **Composition**: Asymmetric layouts, overlaps, generous negative space.
- **Backgrounds**: Gradient meshes, noise textures, shadows.

### Prohibitions
- NUNCA use generic card layouts or emoji icons as UI icons.
- NUNCA use "purple gradient on white" as a default.
