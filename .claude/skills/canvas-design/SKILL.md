# Canvas Design

## When to use this skill

- Creating dynamic banners or thumbnails.
- Generating posters or promotional material programmatically.
- Building custom visual assets for the project.

## Workflow

- [ ] Select appropriate fonts from the local `canvas-fonts` directory.
- [ ] Define the composition and layout on the canvas.
- [ ] Implement drawing logic (gradients, shapes, text).
- [ ] Export the result as an image asset.

## Instructions

- **Fonts**: Use local fonts from `.claude/skills/canvas-design/canvas-fonts/`.
- **Categories**:
    - Serif: Lora, CrimsonPro, etc.
    - Sans-serif: InstrumentSans, Outfit, etc.
    - Display: Boldonse, BigShoulders, etc.
- **Performance**: Ensure efficient drawing operations.
